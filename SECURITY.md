# Security

Please do not open a public issue for a vulnerability or include live job-hunt
data, private search preferences, or connection names in a report.

Use GitHub's private vulnerability reporting for this repository. Include the
affected version, a minimal reproduction using synthetic data, and the impact.

The project is designed to keep private search preferences, connections, local
board data, caches, and generated artifacts outside version control. If any of
those files appear in a commit, remove the data from history before publishing.
